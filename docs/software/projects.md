## Projects

::cards:: cols=2

- title: subagents
  content: >
    A lightweight framework for wiring plain Python functions — and the agents inside them —
    into a graph that runs branches in parallel, routes on conditions, and threads one typed
    state object through the whole thing.
  image: ../images/icons/rocket.svg
  url: https://github.com/sayedshaun/subagents

- title: OneCrawler
  content: >
    Async Python crawling library with sitemap discovery, browser-based extraction, and
    LLM-powered structured output — one Settings object drives it all.
  image: ../images/icons/tools.svg
  url: https://github.com/sayedshaun/onecrawler

- title: OneCrawler Backend
  content: >
    The FastAPI service that turns the library into a platform: REST API for auth, crawl jobs,
    settings and extracted data, with crawling handed to an async job queue.
  image: ../images/icons/work.svg
  url: https://github.com/sayedshaun/onecrawler-backend

- title: LangTrain
  content: >
    PyTorch-backboned Python package for rapid language model development — large-scale data
    tokenisation, distributed training, and evaluation.
  image: ../images/icons/idea.svg
  url: https://github.com/sayedshaun/langtrain

- title: WSD
  content: >
    Dual-architecture pipeline for training and evaluating state-of-the-art Word Sense
    Disambiguation models, with pretrained weights for quick deployment.
  image: ../images/icons/hat.svg
  url: https://github.com/sayedshaun/wsd

- title: Corpus
  content: >
    Core contributor to Bangladesh's national Bangla NLP platform — corpus development,
    syntactic annotation, low-resource language models, and downstream tasks.
  image: ../images/icons/book.svg
  url: https://corpus.bangla.gov.bd

::/cards::
