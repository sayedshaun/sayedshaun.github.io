## Projects

### [OneCrawler](https://github.com/sayedshaun/onecrawler)
Async Python crawling library with sitemap discovery, browser-based extraction, and
LLM-powered structured output — one Settings object drives it all.

### [Corpus](https://corpus.bangla.gov.bd)
Core contributor to a large-scale unified NLP platform, focused on corpus development,
syntactic annotation, low-resource language models, and downstream tasks for Bangla NLP
research.

### [LangTrain](https://github.com/sayedshaun/langtrain)
PyTorch-backboned Python package for rapid language model development — supporting
large-scale data tokenization, distributed training, and evaluation.

### [WSD](https://github.com/sayedshaun/wsd)
Dual-architecture pipeline for training and evaluating state-of-the-art Word Sense
Disambiguation models, with pretrained weights available for quick deployment.
